# 麦门 Code 项目总结

**奶蛙会记住你的口味，越点越懂你。** 麦门 Code（mcd-code）是一个通过真实麦当劳 MCP 选餐和创建订单的 Skill，附带可独立使用的 Python 终端。目标用户是希望奶蛙记住点餐偏好，以及需要结合真实菜单、预算和优惠做决定的麦当劳用户。

## 用户使用流程

Skill 启用先问大致城市、商圈/地标，或附近门店；收到位置后查最近营业门店，明确指定店时核对店名与地址。随后查询菜单、详情、可用券，以官方 calculate-price 返回的金额选餐。用户决定购买后，依次完成具体预览、明确确认、创建订单；支付由用户在官方渠道完成，再查单核实。

## 已完成的功能

- /order：搜店、菜单与默认套餐详情、购物车、门店券、官方算价、地址选择、订单预览、创建和查询。
- /coupons、/points：优惠券和积分商品查询，领取/兑换走同一确认网关。
- /budget、/1024：预算内选餐，以及约 1024 kcal、24.00/102.40 元、1024 积分目标挑战；只比较有真实数值的有限候选。
- /奶蛙：原视频转换的彩色字符大笑与笑声，偏好甜、奶味和圆滚滚小食，推荐仍基于真实菜单和官方试算。
- /奶蛙 --card：1080×1440 静态 SVG 日卡，包含餐品、官方金额、日期、吐槽和 1024 标记；全部 11 种形象按日期轮换。
- /成就：宿主根据真实结果维护次数和趣味称号，没有固定等级表。
- /偏好：保存主动表达的口味和后续真实点餐选择，下次由 Skill 参考；可纠正、忘掉、暂停和清空，开发测试单不导入。
- 点餐创建成功提醒打开麦当劳 App「我的订单」查看或进入待支付订单付款，使用同一会员账号。
- 全部 CLI 命令提供 JSON/JSONL 输出，便于宿主自然语言调用。

## 技术和交易保护

Python 3.10+ 标准库运行，无第三方 Python 依赖。Streamable HTTP 客户端支持 JSON/SSE、会话和工具发现；Token 只从 MCD_TOKEN 读取。默认查询，写操作经过预览、确认和一次性许可。本机 SQLite 只保存身份范围与参数指纹、状态、时间；写请求不自动重发。本机防重不等于服务端幂等保证。

提交版不含模拟客户端、模拟流程测试或演示数据。原开发材料已归档到本机忽略目录。公开检查与验收以当前交付检查及真实接口结果为依据，不把未验证流程写成已完成。

## 真实验证结果

已完成真实门店、菜单、优惠查询、官方算价、目标挑战、JSON 和日卡验收。经用户对具体订单明确确认，2026-10-15 已真实创建一笔 25.50 元外带订单，并通过 query-order 核实待支付。本项目没有执行支付。

取消、真实领券、真实积分兑换、支付/取餐、外送端到端和完整宿主对话尚未真实验收。详见 [VERIFICATION.md](VERIFICATION.md)。
