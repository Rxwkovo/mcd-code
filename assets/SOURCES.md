# 素材来源

笑声、原视频和角色图片统一标注为：**网络来源**。

| 文件 | 来源与处理 |
| --- | --- |
| `characters/*.png`、`nawa.png` | 网络来源。游戏中的全部 11 张 512×512 PNG 原样保留，日卡按日期轮换。 |
| `laugh.json`、`laugh-full.json` | 网络来源。原视频第 3 至 9 秒转换为 24fps、144 帧无损压缩 RGB，用于终端字符播放。 |
| `laugh.wav` | 网络来源。同一视频片段的 PCM 笑声。 |
| `nawa.gif` | 由网络来源视频转换的终端字符动画，不包含菜单、价格或订单数据。 |
| `card-example.png` | 本项目日卡截图，使用网络来源角色。餐品和金额来自 2026-10-15 的真实菜单与官方试算，尚未下单，不代表其他时间或门店的报价。 |

出处链接：[BigNaiWa 游戏](https://yhsome.github.io/BigNaiWa/v1/)、[素材仓库](https://github.com/YHSome/BigNaiWa/tree/main/v1/assets/fruits)、[原视频 BV1p2Tp6REay](https://www.bilibili.com/video/BV1p2Tp6REay/)。游戏没有现成大笑 GIF 或录制笑声，GIF 和 WAV 由原视频转换。
